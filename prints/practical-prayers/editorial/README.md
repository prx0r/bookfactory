# Practical Prayers — content-only editorial handoff

**Created:** 7 November 2026  | **Scope:** `prx0r/bookfactory/prints/practical-prayers` | **Target:** 36 prayers, nine moments, content before formatting.

## Start with these
- `00_explainer_standard.md` — the revised prayer explanation contract, the real point of this project.
- `01_new_introduction.md` — print-ready *proposed* new introduction.
- `02_complete_english_manuscript.md` — all **36** new explanations, practical devotional acts, and recitation decisions (does **not** duplicate unverified Sanskrit).
- `03_content_overlay_proposals.json` — machine-readable complete English `brief`, `logic`, `howto`, `sign` proposals by entry ID.
- `04_new_conclusion.md` — replacement closing page.
- `05_source_qa.csv` — blocking witness/reference/rights checks, linked to corroborating sources.
- `06_five_workstreams_and_agent_brief.md` — five actionable workstreams and what was completed versus what must still be checked.
- `07_publication_gate.md` — final editorial/KDP checklist.
- `08_two_gold_standard_pages.md` — two complete exemplar pages with Sanskrit, literal gloss, ritual and editorial/source separation.
- `apply_preview.py` — makes a candidate JSON from the repo's source entries, without overwriting the repo, preserving Sanskrit fields.

## IMPORTANT
These are editorial content **proposals**, not a certified final edition. They are grounded in the repository's current 36-entry selection; Sanskrit stays in the repository so an agent does not replace source-witness text with accidental retyping. Core errors in the current book require source-level repairs before publication. The editor must explicitly approve these new explanations before merging because the repository's current `AGENTS.md` prohibits agent-authored guide prose.

This package does **not** contain fonts, third-party PDFs, archival audio, the commercial cover or rendered print files.

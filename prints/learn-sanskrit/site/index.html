Rule boxes (whole volume)

Rule box 1 — a + a / a + ā → āAdjacent short a (or a + ā) contract to one long ā. Pāṇini 6.1.101 akaḥ savarṇe dīrghaḥ. Reverse: split ā into a + a when the words demand it.
Rule box 2 — a + e → aiyaṇ sandhi: sadā + eva → sadaiva; brahma + eva → brahmaiva. Reverse: ai may hide a + e.
Rule box 3 — where vs by-whatLocative answers “where?” (hṛdi). Instrumental answers “by/with what?” (cittatayā).
Rule box 4 — 3sg present often ends -tinṛtyati · gāyati · hṛṣyati — same ending, three roots. Discover before the paradigm.
Rule box 5 — mā + imperative = don’tProhibitive mā with imperatives: mā tyaja, mā gṛhāṇa. na negates statements.
Rule box 6 — dual gen/loc = -yorExactly two: anayor, vahnidāhikayor. Not plural -ānām / -eṣu.
Rule box 7 — alaṃ + instrumental = enough ofalaṃ governs the instrumental: alaṃ bhedānukathayā. Substitutes are labelled exercises.
Rule box 8 — -tva + -āt = because of the fact thatAbstract -tva/-tā then ablative -āt builds causal “because”: virodhakatvāt.

Grammar coverage

  • phonology: L1 vowel contraction, L2 anusvāra/visarga, L4 retroflex clusters
  • script: front IAST↔Deva sheet, transition L1–L10 per curriculum
  • sandhi: L1 a+a→ā, a+e→ai, L2 namo, L5 kiṃcit, L7 śaktiś ca, L8 compound ā
  • cases: L2 dative, L3 loc+instr, L6 acc+abl, L7 dual+abl, L8 instr+abl, L10 gen+causal abl
  • number_gender: L7 dual -yor, neuter L9–L10, fem instr L8
  • pronouns: L1 tvaṃ/mama, L5 implied you, L6 tvām, L9 idam
  • verbs: L3 1sg mid, L4 3sg -ti, L5 imperatives, L6 prapadye, L9 lajjate
  • nonfinite: L9 infinitive, L5 participle-like svasthaḥ
  • compounds: L1 mamātmā, L2 viśvamūrti, L6 epithets, L7 dual pair, L10 -tva
  • syntax: L3 means/place, L9 agreement, L10 causal nominals
  • metre: verse vs prose L9–L10

Single-appearance features get labelled exercises, never quoted as Abhinavagupta.

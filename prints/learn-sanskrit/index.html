Rule boxes (the whole volume)

  1. Rule box 1 — a + a / a + ā → ā — Adjacent short a (or a + ā) contract to one long ā. Pāṇini 6.1.101 akaḥ savarṇe dīrghaḥ. Reverse: split ā into a + a when the words demand it.
  2. Rule box 2 — a + e → ai — yaṇ sandhi: sadā + eva → sadaiva; brahma + eva → brahmaiva. Reverse: ai may hide a + e.
  3. Rule box 3 — where vs by-what — Locative answers “where?” (hṛdi). Instrumental answers “by/with what?” (cittatayā).
  4. Rule box 4 — 3sg present often ends -ti — nṛtyati · gāyati · hṛṣyati — same ending, three roots. Discover before the paradigm.
  5. Rule box 5 — mā + imperative = don’t — Prohibitive mā with imperatives: mā tyaja, mā gṛhāṇa. na negates statements.
  6. Rule box 6 — dual gen/loc = -yor — Exactly two: anayor, vahnidāhikayor. Not plural -ānām / -eṣu.
  7. Rule box 7 — alaṃ + instrumental = enough of — alaṃ governs the instrumental: alaṃ bhedānukathayā. Substitutes are labelled exercises.
  8. Rule box 8 — -tva + -āt = because of the fact that — Abstract -tva/-tā then ablative -āt builds causal “because”: virodhakatvāt.

  • number_gender: L7 dual -yor, neuter L9–L10, fem instr L8

  • verbs: L3 1sg mid, L4 3sg -ti, L5 imperatives, L6 prapadye, L9 lajjate
